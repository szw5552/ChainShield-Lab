AI-assisted npm supply-chain defense agent

ChainShield Lab 的目的，是保護使用者在下載與安裝 npm 套件時，不被惡意套件的漏洞、 可疑供應鏈行為或 postinstall 攻擊傷害。它會先收集 evidence，通過 Snyk、Socket、 OpenShell 三道 gate，再由 Supervisor Decision 產出可追蹤的結果：可以安全繼續 (`allow`)、必須阻擋安裝 (`deny`)，或證據不足需要人工複查 (`manual_review`)。

Gate Conditions

三道 gate 的判斷條件要讓評審一眼看懂

Snyk Gate 已知漏洞
  • 必須阻擋：發現高風險或重大已知漏洞（high / critical vulnerability）。
  • 可以通過：沒有高風險或重大漏洞；低中風險會列入提醒，不直接阻擋。
  • 人工複查：Snyk 報告缺失、格式壞掉，或 live scanner timeout。
Socket Gate 供應鏈風險
  • 必須阻擋：命中組織政策違規、惡意程式風險或供應鏈風險。
  • 必須阻擋：套件健康狀態不佳，或出現可疑安裝行為。
  • 人工複查：Socket 輸出無法解析，或 policy 狀態不明。
OpenShell Gate 安裝期 containment
  • 可以通過：有證據顯示敏感資料讀取已被擋下（filesystem read block）。
  • 可以通過：有證據顯示不明 API 外連已被擋下（network egress block）。
  • 人工複查：任一阻擋紀錄缺失，或 evidence 尚未清理敏感資訊。
deny 任何 static gate deny 會直接阻止 host install。 manual_review 證據缺失、不一致或 Worker concern。 allow 必要 gate pass 且 evidence 足夠。

Sandbox Containment

就算壞東西動起來，也只能在受控環境留下證據

NemoClaw / OpenShell Gate 是第三層示範：它不把 static deny 改成 allow， 只證明 sandbox policy 能阻擋「模擬敏感資料讀取風險」（synthetic canary）， 以及「不明 API 外連請求」（synthetic network egress）。

01

阻擋敏感資料讀取

惡意安裝腳本嘗試讀取模擬敏感資料時，NemoClaw / OpenShell sandbox 必須留下「已阻擋」紀錄（filesystem read block）。

02

阻擋不明 API 外連

惡意安裝腳本嘗試把資料送到外部 API 時，default-deny policy 必須擋下連線（network egress block）。

03

只保留已清理證據

輸出 log 只保留事件類型、觸發規則、時間與報告位置，不保存真實秘密或敏感路徑（sanitized evidence）。

AI Worker Boundary

AI 負責整理證據，不負責安全裁決

Nemotron / Codex / Claude Worker 只能讀 sanitized evidence packet，產生 reviewer-friendly summary。 最終可以安全繼續、必須阻擋安裝、或需要人工複查，仍由「Supervisor：固定規則裁決」這個環節決定。

Input

worker-task-packet.json

給 AI Worker 的整理任務單：只列出要看的報告位置、檢查重點與這次任務資訊，不包含秘密，也不要求執行命令。

Allowed

安全整理後的證據摘要

AI 只能回報三種摘要狀態：clear 代表沒有補充疑慮，concern 代表看到疑點，inconclusive 代表證據不足無法整理出明確結論。

Blocked

AI 不能自己決定放行或阻擋

AI 也不能要求系統去跑 shell、scanner、sandbox，或觸發 npm 安裝流程；它只負責整理已經清理過的證據。

Final Outputs

可追溯的判斷依據及成果

Supervisor Decision 會把 gate evidence、agent invocation evidence、reasons 和 next actions 固定成可追蹤 artifact，讓評審直接從輸出理解每個裁決。

decision JSON

{
  "decision": "deny",
  "primary_reasons": [...],
  "gate_results": [...],
  "agent_invocations": [...]
}

Markdown summary

30 秒內可讀：結果、primary reasons、missing gates、next actions、reports/logs refs。

Decision states

allow deny manual_review

每個結果都必須能回追到 Snyk、Socket、OpenShell 或 Worker evidence。
